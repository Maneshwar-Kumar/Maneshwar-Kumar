## More detail

### [Voice AI Deployment Lab](https://github.com/Maneshwar-Kumar/voice-ai-deployment-lab)

An interactive, provider-neutral deployment workbench for taking an enterprise voice-AI use case from discovery to controlled production. It covers business-case sizing, solution architecture, integration contracts, evaluation gates, risk controls, phased rollout, observability, incident response, automated tests, and CI/CD.

### [Expert Call Intelligence](https://github.com/Maneshwar-Kumar/expert-call-intelligence)

A Claude Code plugin that converts raw expert-call transcripts into validated summaries, an atomic evidence ledger, contradiction-aware claim clusters, and provenance-aware case Q&A. Deterministic Go tooling handles hashing, extraction, validation, Word rendering, and retrieval.

### [India VC Intelligence](https://github.com/Maneshwar-Kumar/india-vc-intelligence)

A Python and Streamlit prototype integrating search, RSS, OpenAI analysis, deduplication, SQLite persistence, and an interactive dashboard for monitoring Indian venture and startup themes.

### [Source Discipline for AI Research](https://github.com/Maneshwar-Kumar/anti-fab-skill)

A compact research guardrail that distinguishes fetched facts, derived calculations, and assumptions; blocks unsourced quotations; and triggers adjacent-claim review when an error is found.
